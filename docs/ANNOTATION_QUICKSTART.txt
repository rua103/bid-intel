政府采购公告标注任务：队友操作卡

你只负责人工核对，页面不调用模型，也不需要 API Key。

1. 先把收到的 ZIP 解压到一个固定文件夹。里面有一个 *.bundle.json 和 sources 文件夹；两样都要保留。
2. 打开协调员发你的标注页面链接，点“载入我的标注任务”，选择这个 ZIP 里的 *.bundle.json。
3. 看左侧原文和原始文件名，按公告原文填写右侧。解析文字只是搜索/定位线索；扫描件或解析不清的文件要从解压目录的 sources 文件夹打开核对。
4. 原文没写的字段留空，不猜。金额统一填人民币元；中标方也要加进投标主体。按原文填写包号；原文未分包时填 default。
5. 一条公告所有包都核对完，才勾“本公告已对照原文”。看到红色提示先按提示修好。改过内容后需要重新核验。
6. 页面会自动保存在当前浏览器。中途停下前点“下载进度备份”。做完全部条目，点“导出已核验 Gold”，把下载得到的 *.gold.reviewed.json 文件交给协调员，不要重命名。

不能确认、附件缺失/打不开、包号不确定：不要猜，不要勾核验，记下公告 ID 并联系协调员。
