人工标注任务 · 队友操作卡
=========================

你只做人工核对。页面不联网、不调模型、不需要 API Key。
详细版见 docs/ANNOTATION_ANNOTATOR.md


你要拿到两样东西
----------------
  ① 一个 ZIP，名字是 pilot-a.ready.zip（或 pilot-b.ready.zip）
  ② 一个网页链接，形如 http://192.168.x.x:5173/annotation.html

  缺任何一样就找协调员，不要自己想办法。
  A 拿 pilot-a，B 拿 pilot-b，不要拿错，也不要看对方的答案。


五步做完
--------
  1. 解压 ZIP 到固定文件夹。里面要有 pilot-a.bundle.json 和 sources\ 两样，都要留着。

  2. 浏览器打开那个链接。

  3. 点「载入我的标注任务」，选 pilot-a.bundle.json。
     加载成功的标志：页面顶部显示任务名和总条数（应该是 6）。

  4. 逐条填写。左边是原文，右边是要填的表单。
     每条公告：对着原文填七字段 + 采购单位 + 中标方 + 投标主体，
     填完才勾「本公告已对照原文」。
     必要时打开 sources\ 里的原附件核对——扫描件的解析文字只是线索。

  5. 6 条全勾完，点「导出已核验 Gold（6/6）」，
     把下载的文件直接发给协调员。不要重命名。


三条总原则
----------
  · 原文没写就留空。不猜、不推理、不写"应该是"。
  · 页面上已有的内容是机器猜的，不是答案。必须自己对照原文。
  · 公司名、品牌名照抄原文，不要自己统一简称。


常见情况
--------
  原文「见附件」但附件里也没有  → 留空
  原文「￥1472.6085 万元」      → 填 14726085（换算成元）
  原文「2台」                  → 数量填 2（不带单位）
  甲公司中标                    → 中标方 和 投标主体 两个列表都要填它
  没写谁没中标                  → 投标结果选「结果未披露」，不要猜成未中标
  「甲乙联合体」中标            → 就填这一个，不要拆成甲、乙
  原文没分包                    → 包号填 default


不能勾核验的情况
----------------
  标的行七字段全空 / 包号重复或为空 / 主体名为空 / 数字填了非法内容。
  页面会变灰并给出提示，按提示改完再勾。

  改过任何内容，已勾的核验会自动取消——这是故意的，改了就要重新对照。


中途离开
--------
  页面自动保存在当前浏览器里，但换电脑/清缓存会丢。
  离开前一定点「下载进度备份」。


拿不准的时候
------------
  不要猜。留空，记下公告 ID 和包号，告诉协调员。
  附件打不开、是乱码、或看起来是验证码页 —— 跳过这条并通知协调员。


注意
----
  本地评测结果不是官方成绩，不要对外当作准确率宣称。
  不要把整份官方语料外传；这个包只含你负责的那几条。
