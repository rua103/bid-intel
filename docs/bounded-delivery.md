# 有界并发与评测器

后端后台任务和三路线评测器使用同一套宿主机资源额度，分别限制文档处理、模型请求和等待队列。生产任务按公告隔离进程，并保存公告级进度、模型配置快照、请求缓存和幂等入库收据；评测器按路线顺序执行，同一路线内可用 `--concurrency` 控制公告并行度，默认仍为 1。

该实现面向单机部署：所有 API worker、任务协调器和评测进程必须共享同一个本机 `JOB_RUNTIME_DIR`。文件锁不提供 NFS 或跨主机调度保证。模型请求不自动重试 429 或切换端点；连接中断后，远端可能已处理并计费，恢复不能保证零重复请求。真实端点、OCR/Office 负载及 Ubuntu 决赛环境仍需单独验收。

任务 API、配置与运维命令见[生产任务说明](bounded-jobs.md)，三路线运行和 final 报告要求见[评测器说明](bounded-route-evaluation.md)，合成验证方法、结果与容量边界见[离线验证记录](bounded-validation.md)。
